  1. Estructura básica de una página HTML

    2. HTML es ul lenguaje de marcas funciona con etiquetas. Su estructura es así:

    <Etiqueta de apertura><Contenido><Etiqueta de cierre>

    <!DOCTYPE html>,<html>, <head> y <body> son etiquetas fundamentales.

    • <!DOCTYPE html> le indica al navegador qué tipo de documento es el que esta ejecutando.
    • <html> es la etiqueta principal del documento. Todo el contenido de la página web va detro de ella.
    • <head> es la sección de la página que no es visible directamente en el navegador. Aquí van el título y los datos generales de la página web.

      • <title> se usa para darle un título a la página web. Este título será visible en la pestaña del navegador.

      • <meta> es información que el motor de búsqueda usa para analizar el contenido que se encuentra en la web. Los metadatos más usados en esta etiqueta son:

        • <charset> especifica la codificación de caracteres de la página.

        • <name> es el nombre del metadato, y debe usarse en conjunto con "content".

        • <http-equiv> se utiliza para especificar una directiva.

        • <content> es un valor asociado a <name> y <http-equiv>.

    • <body> es la sección de la página que es directamente visible en el navegador.
      • <p> se usa para hacer párrafos.
      • <pre> se utiliza para escribir un texto tl y como viene en cl código, conlos saltos demlínea, los espacios, etc...

  2. Etiquetas relacionadas con el texto

    • Caracteres especiales son algunos caracteres que deben ser escritos por comandos. En la imagen adjuna hay una tabla con algunos de ellos: 
    • Comentarios: son textos que se ponen en el código pero no afectan en nada al código, solo sirve para que el delarrollador lo vea. Así es su estructura: 
					<!-- COMENTARIO -->>
    • La etiqueta<hr> sirve para insertar una línea. Esta etiqueta tiene varios atributos:
      • "Align" sirve para establecer la posición en la que se encuentra la línea.
      • "width" srive para establecer el ancho de la línea.
      • "size" sirve para establecer la altura de la línea.
      • "noshade" sirve para eliminar el sombreado de la línea.
    • La fuente se establece con la etiqueta <font>, y tiene los siguientes atributos:
      • "face" es el nombre de la fuente.
      • "color" es el color que se le va a poner al texto. Se escribe en código exadecimal o en texto predefinido.
      • "size" indica el tamaño del texto.
    • Resaltos de texto:
      • <b>: negrita.
      • <i>: cursiva.
      • <u>: Subrayado.
      • <s>: tachado.
      • <tt>: teletipo.
      • <big>: aumenta el tamaño de la fuente.
      • <small>: disminuye el tamaño de la fuente.
    • También existen los encabezados, que van según el tamaño desde "h1" hasta "h6".

  3. Imágenes y enlaces

    • Las imágenes se escriben con etiquetas de línea, por lo que no necesitan etiquetas de cierre. Esta es su estructura:
					<img scr="Ruta de la imagen" alt="x">
					"src" sirve para indicar la ruta de la imagen a exponer.
					"alt" es un texto alternativo para ponerle a la imagen y describirla.
      • "width" es el ancho que ocupará la imagen.
      • "height" es el alto que ocupará la imagen.

        • En caso de que solo se introduzca uno de los dos valores, el valor no puesto se calculará automáticamente para guardar la proporción.

    • Las Figuras son imágenes con textos asociados. Su estructura es así:
					<figure>
						<img...>
						<figcaption>...</figcaption>
					</figure>
    • Enlaces 
      Los enlaces se escriben con <a>...</a>. Tiene varios atributos:
						
        
							
      • href: indica la dirección del enlace.
        • 
							
      • target: si no tiene valor, el enlace se abrirá en la misma ventana. Si tiene de valor target="_blank", se abrirá en una ventana nueva.

  4. Listas y viñetas

    Las listas permiten ordenar y estructurar información. Hay dos tipos: las ordenadas y las no ordenadas:

    • Ordenadas: 
      Las ordenadas pueden ponerse con números, letras o números romanos. Su estructura es así:
						<ol>type="A/a/1/i/I" start="el número con el que empieza">
    • Ordenadas: 
      Las no ordenadas pueden ponerse con círculos, circunferencias o cuadrados. Su estructura es así:
						<ol>type="square, circle ó disc">
    • Cada elemento en la lista se incluye con la etiqueta <li>...</li>
